Fills the gap between progress (one bar) and timeline (chronological events): stepper says where you are in a sequence of discrete states. Status values are consumer-defined; the widget only consumes the resolved tone via statusMap. Selecting a vertical row emits onSelect(step.id) to drive a sibling widget.
